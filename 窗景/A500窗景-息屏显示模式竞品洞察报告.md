## 二、电视竞品深度分析

### 2.1 三星 The Frame · Art Mode（画壁艺术电视）

**产品定位：** 将电视变成艺术画廊，强调"电视即画作"的家居美学

**核心功能特性：**

| 功能 | 详情 |
|------|------|
| **艺术模式** | 待机时自动展示艺术作品，关闭时不再是黑屏 |
| **三星艺术画廊（Art Store）** | 近千幅世界知名艺术作品，支持微信扫码注册 |
| **亮度传感器** | 自动感知环境光线调节显示亮度，节能优化 |
| **磁吸式艺术边框** | 可更换边框匹配不同画风/家装风格 |
| **可旋转落地支架** | 支持横竖屏旋转展示 |
| **VisionAI（2025款LS03F）** | AI画质增强 + 智能交互 |

**内容分层策略：**

```
┌─────────────────────────────────────────────────────┐
│                    三星艺术画廊                        │
├─────────────────────────────────────────────────────┤
│  免费精品内容  │  艺术流媒体  │  会员专属作品（2500+）   │
│  (限时体验)    │  (订阅制)    │  (需付费解锁)          │
└─────────────────────────────────────────────────────┘
```

**分类体系：**
- 热门作品 / 大师作品 / 动态作品 / 免费作品
- 博物馆系列（与大英博物馆、卢浮宫等合作）
- 艺术家专区（支持按艺术家检索）

**参考链接：**
- 产品官网：https://www.samsung.com.cn/lifestyle-tvs/the-frame/art-mode/
- Art Store介绍：https://www.samsung.com/hk/tvs/art-tv/

### 2.2 三星 QLED · Ambient Mode（环境模式）

**产品定位：** 让电视"消失"在墙壁中，实现与家居装饰的完美融合

**核心功能特性：**

| 功能 | 详情 |
|------|------|
| **墙壁融合** | 通过算法匹配墙壁颜色/图案，使电视与背景融为一体 |
| **我的相册（My Album）** | 通过SmartThings上传个人照片，变身个人艺廊 |
| **装饰性墙面图案** | 内置多款装饰性图案供选择 |
| **信息展示** | 显示天气、时间、日程等实用信息 |
| **自动亮度调节** | 黑暗环境中自动降低亮度，节能且不刺眼 |
| **休眠定时器** | 可设置环境模式自动关闭时间（默认5小时） |
| **一键清除** | 可快速清除所有上传的个人照片 |

**交互方式：**

```
启动方式：
① 遥控器 → 直接按「环境模式按钮」
② Smart Hub → 选择「环境模式图标」

照片传输（SmartThings）：
设备列表 → 选择电视 → Ambient Mode → My Album → Select photos
```

**技术亮点：**
- 内置亮度检测传感器
- AI算法识别墙壁颜色和纹理
- 支持2019年及以后的QLED型号

**参考链接：**
- 官方使用指南：https://www.samsung.com/hk/support/tv-audio-video/how-to-use-ambient-mode-on-samsung-qled-tv/
- 功能介绍：https://kes.recmg.com/tech/renda/what-is-samsung-ambient-mode/

### 2.3 LG OLED · Gallery Mode（画廊模式）

**产品定位：** 将OLED电视变成4K/8K高清艺术展示屏

**核心功能特性：**

| 功能 | 详情 |
|------|------|
| **高清艺术展示** | 4K/8K分辨率艺术作品展示 |
| **虚拟边框效果** | 模拟真实画框，增强画廊感 |
| **主题幻灯片** | 支持按主题/艺术家/流派组织，自动切换 |
| **环境音效** | 自带主题背景音乐，可开关 |
| **横竖屏切换** | 部分型号支持横竖旋转 |
| **云端图库** | 所有内容来自LG内置云端数据库 |

**局限性：**

| 问题 | 说明 |
|------|------|
| 无个性化定制 | 不能上传个人照片，无法自定义显示时长 |
| 需联网 | 必须保持网络连接才能加载云端内容 |
| 黑屏过渡 | 切换图片时有黑屏过渡效果 |
| 整体体验 | 业界认为不如三星The Frame |

**交互方式：**

```
主屏幕 → App → Art Gallery → My Themes → 选择图片 → OK全屏显示
切换图片：遥控器「向下方向键」
```

**参考链接：**
- 功能详解：https://settingslab.com/lg-gallery-mode-explained/
- 开启教程：https://smartdigihere.com/gallery-mode-on-lg-tv/

### 2.4 创维 S81/W81 · TrensAI AOD（双息屏显示）

**产品定位：** 全球首款实现电视息屏显示的国产旗舰，强调智慧生活助手

**核心创新：** AOD DUAL 双息屏显示技术

| 技术亮点 | 详情 |
|----------|------|
| **局部点亮** | 仅点亮屏幕局部区域显示信息，降低功耗 |
| **同屏双系统** | 主屏正常播放 + 副屏AOD显示 |
| **语音交互** | 息屏状态下支持远场语音唤醒 |
| **视觉交互** | 支持摄像头视觉交互（部分型号） |
| **信息显示** | 时间、天气、日程、智能家居状态等 |

**功能场景：**

```
待机场景：
├── 经过电视 → 显示时间/日期/天气
├── 语音唤醒 → "今天天气怎么样？" → 语音播报
├── 智能家居联动 → 显示设备状态/提醒
└── 家庭留言板 → 家庭成员互动
```

**技术基础：**
- 依托OLED自发光特性（像素级控光）
- Swaiot小维智联生态
- TrensAI智能生活管家

**参考链接：**

- 功能详解：https://zhuanlan.zhihu.com/p/82738832

### 3.1 苹果 iPhone 全天候显示（Always-On Display）

**发展历程：** iPhone 14 Pro系列首发 → iPhone 17全系开放

**核心功能设计：**

| 功能 | 详情 |
|------|------|
| **锁屏信息保留** | 显示壁纸、时间、小组件、通知（可自定义） |
| **超低刷新率** | 1Hz刷新率，极低功耗 |
| **智能调暗** | 移开视线后自动变暗锁定 |
| **灵动岛融合** | 灵动岛与AOD无缝衔接（iOS 17+） |
| **天气动态壁纸** | iPhone 17新增锁屏天气动态显示 |

**差异化亮点：**
- **信息密度高：** 可显示大部分锁屏内容，不只是时间
