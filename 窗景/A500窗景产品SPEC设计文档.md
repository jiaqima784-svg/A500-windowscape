## 1. 产品概述

### 1.1 产品定位

A500 窗景是专为智能电视打造的新一代视觉体验产品，**重新定义电视在非观看时段的价值**。通过将实时天气、季节变化与沉浸式动态影像结合，窗景让电视成为一面「懂你的智能窗户」，为用户提供随时间、天气、季节流转的动态视觉体验。

**核心价值主张**：
- **新鲜感**：每次打开均有不同的视觉效果，永远不会重复
- **沉浸感**：深度还原「透过窗户看世界」的临场体验
- **美感**：精选东方美学场景，将艺术融入日常生活

### 1.2 目标用户

| 画像 | 特征 | 核心诉求 |
|------|------|---------|
| 都市独居青年 | 25-35岁，独居，注重生活品质 | 消除孤独感，营造家的氛围 |
| 品质生活家庭 | 30-45岁，有孩家庭，追求家居美学 | 提升客厅格调，兼具装饰与功能 |
| 助眠需求用户 | 25-55岁，睡眠质量欠佳 | 助眠陪伴，减少入睡焦虑 |
| 居家办公者 | 28-45岁，WFH人群 | 营造专注氛围，提升居家办公体验 |

## 2. 息屏显示模式（AOD）

### 2.1 设计理念

息屏显示模式是 A500 窗景的**核心低功耗陪伴模式**，在用户不主动交互时，以极低功耗维持一幅「微光窗景」，实现：

- **节能**：整机功耗 < 5W，约为标准模式的 1/20
- **美观**：保留窗景核心美学要素（光影、氛围、时间感）
- **无缝**：从标准模式 → MiniLED 模式 → AOD 模式过渡自然，用户感知为零干扰

### 2.2 触发逻辑

```
用户操作 ──▶ 标准模式（全亮度）
  │
  ├─ 无操作 1~5min（可配置）
  │     ▼
  │   MiniLED 模式（类纱帘效果，中等亮度）
  │
  ├─ 无操作 15~30min（可配置）
  │     ▼
  │   息屏显示模式（AOD，极低亮度）
  │
  └─ 检测到用户靠近 / 遥控器按键 / 触屏
        ▼
      唤醒 → 标准模式（带入场动画）
```

### 2.3 三种滤镜风格

#### 风格 A：微光写实（Glimmer Realistic）

- **理念**：最大程度保留窗景的写实感，仅将亮度和对比度降至极低
- **渲染方式**：原始渲染管线 → 亮度曲线压缩 → 对比度映射 → 色彩去饱和（降至 15%）
- **适用场景**：所有场景
- **功耗等级**：中（约 4W）

#### 风格 B：水墨剪影（Ink Silhouette）

- **理念**：将窗景抽象为水墨画风格的剪影层，只保留轮廓和层次关系
- **渲染方式**：边缘检测 → 轮廓提取 → 2~3 层灰度叠加 → 水墨晕染后处理
- **适用场景**：梦江南/水调楼阁、大都会/文艺老街（最匹配东方/复古美学）
- **功耗等级**：低（约 3W）

#### 风格 C：星座光点（Starlight Dots）

- **理念**：将窗景中最核心的视觉信息提炼为稀疏的光点阵列，极致极简
- **渲染方式**：场景特征点提取 → 稀疏光点映射 → 呼吸闪烁
- **适用场景**：新城际/科技新城（科技感最强）、寂静海/海边小屋（星空感）
- **功耗等级**：极低（约 2W）

### 2.4 滤镜风格参数对比

| 参数 | 微光写实 A | 水墨剪影 B | 星座光点 C |
|------|-----------|-----------|-----------|
| 全局亮度 | 3%-12% | 5%-18%（3级） | 2%-12%（光点） |
| 背景色 | 场景映射 | #0D1117 | #0A1628 |
| 饱和度 | 15% | 0%（纯灰度） | 80%（冷蓝系） |
| 渲染负载 | 中 | 低 | 极低 |
| 预估功耗 | ~4W | ~3W | ~2W |
| 最佳场景 | 全场景 | 梦江南/大都会 | 新城际/寂静海 |

### 2.5 信息挂件设计

AOD 模式下，屏幕底部固定显示一个**极简信息挂件**：

```
┌─────────────────────────────────────────┐
│  23:42    ☁ 阴    🌡 22°C     ·· 睡眠中  │
│  时间      天气      温度       状态     │
└─────────────────────────────────────────┘
```

**挂件组成**：

| 元素 | 内容 | 刷新频率 | 可见性 |
|------|------|---------|--------|
| 时间 | HH:MM，24小时制 | 每分钟 | 常显 |
| 天气 | 图标 + 简述（晴/阴/雨/雪） | 每30分钟 | 常显 |
| 温度 | 当前室外温度 ±1°C | 每30分钟 | 常显 |
| 状态 | 小圆点 + "睡眠中"文字 | 按需 | 仅在睡眠模式时显示 |

### 2.6 进入/退出动画

| 阶段 | 时长 | 动画效果 |
|------|------|---------|
| 标准 → MiniLED | 2.0s | 类纱帘落下，亮度渐降 |
| MiniLED → AOD | 3.0s | 纱帘渐隐，滤镜切换，挂件淡入 |
| AOD → 标准（唤醒） | 2.0s | 中心光晕扩散，画面渐亮 |

## 3. 空间场景功能

### 3.1 设计理念

空间场景是 A500 窗景的**主动体验模式**，在用户主动进入时提供完整的沉浸式视觉内容。强调：
- **叙事性**：不是简单的图片轮播，而是有时间感和故事感的场景
- **互动性**：叙事角色（松鼠、船夫、小鸟）带来生命感
- **情感连接**：每日一诗的仪式感，建立用户与产品的情感纽带

### 3.2 五大场景通道

| 场景通道 | 视觉主题 | 核心场景 | 最佳时段 | 叙事角色 |
|---------|---------|---------|---------|---------|
| **新城际** | 科技新城 | 城市天际线、霓虹夜景、现代建筑 | 夜间 | 无人机、灯光 |
| **大都会** | 文艺老街 | 梧桐树下、老式路灯、弄堂深处 | 暮间/夜间 | 猫咪、灯笼 |
| **梦江南** | 水调楼阁 | 西湖山水、亭台楼阁、水乡古镇 | 全天 | 摇橹船、白鹭 |
| **曼陀罗** | 郊外庄园 | 薰衣草田、森林秘境、花园城堡 | 晨间/日间 | 松鼠、蝴蝶 |
| **寂静海** | 海边小屋 | 礁石海浪、落日码头、星空银河 | 全天 | 海鸥、灯塔 |

### 3.3 核心功能模块

#### 3.3.1 每日一诗

**功能描述**：从待机唤醒时展示一句匹配当前时间、季节、天气的诗词，带来仪式感。

**诗词匹配逻辑**：

```
诗词选择 = f(当前时段, 当前天气, 当前季节)
```

| 时段 | 适配诗词调性 | 示例 |
|------|------------|------|
| 晨间（06:00-10:00） | 清新、希望、生机 | "几处早莺争暖树，谁家新燕啄春泥" |
| 日间（10:00-16:00） | 明朗、开阔、积极 | "毕竟西湖六月中，风光不与四时同" |
| 暮间（16:00-20:00） | 温馨、回忆、沉思 | "落日楼头，断鸿声里，江南游子" |
| 夜间（20:00-06:00） | 静谧、悠远、禅意 | "月落乌啼霜满天，江枫渔火对愁眠" |

**展示规范**：

| 参数 | 值 |
|------|---|
| 展示时长 | 5秒（可配置） |
| 淡入时长 | 1.2秒 |
| 淡出时长 | 1.0秒 |
| 字体 | 思源宋体 / 系统衬线字体 |
| 字号 | 28px（4K基准） |
| 颜色 | rgba(255, 255, 255, 0.8) |

#### 3.3.2 窗剧场叙事角色

**角色设计原则**：

1. **真实性**：角色的行为模式符合真实动物习性
2. **低干扰**：角色不会占据画面主体，保持场景的沉浸感
3. **随机性**：角色的出现位置、频率具有随机性，避免重复感

**已设计角色**：

| 角色 | 出现场景 | 行为模式 | 出现频率 |
|------|---------|---------|---------|
| 松鼠 | 曼陀罗/森林场景 | 跳跃、觅食、观望 | 中等 |
| 摇橹船 | 梦江南场景 | 缓慢划过水面 | 较低 |
| 白鹭 | 梦江南场景 | 飞起、降落、涉水 | 中等 |
| 小猫 | 大都会场景 | 踱步、躺卧、观望 | 中等 |
| 海鸥 | 寂静海场景 | 盘旋、俯冲 | 较低 |

#### 3.3.3 智能时间/天气联动

**时段划分**：

| 时段 | 时间范围 | 天空色彩 | 主要光源 |
|------|---------|---------|---------|
| 晨间 | 06:00-10:00 | 橙黄渐变 → 天蓝 | 朝阳 |
| 日间 | 10:00-16:00 | 天蓝 → 淡蓝 | 太阳 |
| 暮间 | 16:00-20:00 | 金橙 → 紫红 | 夕阳 |
| 夜间 | 20:00-06:00 | 深蓝 → 墨黑 | 月光/星光 |

**天气效果**：

| 天气 | 视觉表现 | 音效配合 |
|------|---------|---------|
| 晴 | 通透蓝天，光影分明 | 鸟鸣、风声 |
| 阴 | 灰蒙蒙的天空，减弱的对比度 | 风声 |
| 雨 | 雨滴下落效果，水面涟漪 | 雨声 |
| 雪 | 雪花飘落，地面积雪 | 寂静/风声 |
| 雾 | 雾气弥漫，视野模糊 | 寂静 |

### 4.2 重点竞品分析

#### 4.2.1 三星 The Frame（画壁艺术电视）

**产品定位**：将电视变成一幅艺术品，主打"电视不是黑屏，是墙上的一幅画"

**核心功能**：
- **艺术模式**：待机时展示艺术作品，有1000+艺术馆藏
- **Matte Display**：哑光屏幕，减少反光，模拟真实画框质感
- **定制边框**：可更换画框颜色，匹配家居风格
- **My Collection**：用户可上传个人照片作为展示内容

**技术亮点**：
- 2025款新增Vision AI，可根据光线自动调节艺术作品显示效果
- 支持动态艺术（带微妙的动画效果）
- 功耗优化：艺术模式下功耗约30-40W（仍较高）

**优势**：
- 品牌调性高，设计感强
- 内容库丰富（与大英博物馆等合作）
- 哑光屏幕技术独特

**劣势**：
- 缺乏中国本土化内容（无诗词、无东方场景）
- 价格较高（65寸约15000元起）
- 场景内容以西方艺术为主

**对A500的启示**：
1. 艺术模式的价值已被市场验证，窗景可以借鉴"让电视成为艺术品"的理念
2. 但需要在内容上做本土化，A500的东方美学场景是差异化核心
3. 哑光屏幕技术可作为硬件选型参考

#### 4.2.2 创维 AOD（TrensAI AOD）

**产品定位**：智能生活管家，在息屏状态下提供实用信息

**核心功能**：
- **双息屏显示**：可同时显示时间和IoT设备状态
- **语音唤醒**：支持远场语音，息屏状态下也可语音交互
- **智能提醒**：根据用户习惯推送日程、天气等信息
- **音乐控制**：息屏状态下显示歌词和播放控制

**技术亮点**：
- 利用OLED自发光特性，仅点亮部分像素
- 响应速度快，从息屏到交互延迟低
- 与智能家居生态深度整合

**优势**：
- 实用性强，信息展示丰富
- 语音交互便捷
- 与IoT设备联动

**劣势**：
- 视觉美学不够精致
- 缺乏文化内涵
- 场景内容单一

**对A500的启示**：
1. 信息挂件设计可借鉴，但需简化并提升视觉美感
2. 语音交互可作为辅助功能
3. 与IoT联动可作为未来扩展方向

#### 4.2.3 小米电视6 OLED

**产品定位**：高性价比OLED电视，AOD作为差异化功能

**核心功能**：
- **AOD时钟**：支持多种时钟样式（数字、指针、艺术字）
- **天气展示**：在AOD模式下显示天气信息
- **个性定制**：支持自定义显示内容和颜色

**技术亮点**：
- 利用OLED特性实现低功耗息屏
- 与小米生态联动（米家设备状态）
- MIUI TV系统整合

**优势**：
- 性价比高
- 系统生态完善
- 智能联动能力强

**劣势**：
- AOD内容较为简单
- 缺乏场景沉浸感
- 品牌调性偏科技感，缺乏艺术感

**对A500的启示**：
1. 性价比路线可作为定价策略参考
2. 生态联动是加分项，但核心仍是体验本身
3. 需避免"功能堆砌"，聚焦核心体验

### 4.3 市场机会分析

#### 4.3.1 市场空白点

| 空白点 | 描述 | 机会 |
|--------|------|------|
| **东方美学场景缺失** | 现有竞品以西方艺术/现代科技为主 | A500的五大东方场景是独特优势 |
| **诗词文化融合** | 无竞品将诗词与智能显示结合 | 每日一诗创造差异化仪式感 |
| **叙事性场景** | 现有产品以静态展示为主 | 窗剧场的叙事角色带来"生命感" |
| **助眠场景优化** | 现有产品缺乏专门的助眠模式 | AOD的极低亮度+舒缓视觉是机会 |

#### 4.3.2 用户痛点与解决方案

| 痛点 | 现有方案 | A500解决方案 |
|------|---------|------------|
| 电视待机时是黑屏，影响美观 | 三星艺术模式（价格高） | 窗景提供高性价比的替代 |
| 缺乏文化内涵，电视只是电子产品 | 无有效解决方案 | 每日一诗+东方场景创造文化氛围 |
| 睡眠时需要背景氛围，但电视太亮 | 关闭电视或手机播放 | AOD极低亮度+舒缓视觉 |
| 场景内容容易审美疲劳 | 无有效解决方案 | 天气/季节/时段联动，永不重复 |

## 6. 技术实现要求

### 6.1 渲染管线架构

```
标准渲染管线:
  [场景资源] → [动画合成] → [时间/天气叠加] → [色彩管理] → [显示输出]

AOD渲染管线:
  [场景资源] → [动画合成] → [时间/天气叠加]
    → [AOD滤镜选择] ──┬─▶ [微光写实滤镜] ─┐
                      ├─▶ [水墨剪影滤镜]  ├→ [亮度/饱和度映射]
                      └─▶ [星座光点滤镜] ─┘
    → [信息挂件叠加] → [MiniLED背光映射] → [低帧率输出] → [显示输出]
```

### 6.2 核心模块需求

| 优先级 | 模块 | 说明 |
|--------|------|------|
| P0 | 实时滤镜渲染管线 | 支持3种滤镜的实时切换 |
| P0 | 超低帧率控制 | 确保MiniLED背光与低帧率同步 |
| P0 | 功耗监控与自适应 | 实时监控功耗，自动调节 |
| P0 | MiniLED背光精细控制 | 分区背光，仅保留内容区域 |
| P1 | 播放上下文序列化 | 进入AOD前保存状态，退出后恢复 |
| P1 | 时间/天气数据接口 | 日出日落时间、实时天气 |
| P1 | 信息挂件渲染组件 | 半透明背景、毛玻璃效果 |
| P1 | 进入/退出动画系统 | 精确实现所有动画关键帧 |
| P1 | 人体接近传感器集成 | 毫米波雷达/红外检测 |
| P2 | 音频伴随处理 | AOD模式下音频降至20% |
