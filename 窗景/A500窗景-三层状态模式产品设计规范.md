## 1. 设计理念与核心框架

### 1.1 设计背景

参照iPhone全天候显示（Always-On Display）的设计理念，重新定义A500窗景的息屏状态层次：

> **核心洞察**：用户在不使用电视时，电视可能处于"有人在场但未观看"的状态。现有一刀切的AOD模式无法覆盖所有场景，需要更精细的状态分层来实现功耗与体验的平衡。

### 1.2 三层状态架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                        A500 窗景 · 三层状态架构                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐           │
│  │    黑屏      │ ←→  │   息屏显示   │ ←→  │    屏保      │           │
│  │ Dark Screen │     │     AOD     │     │Screen Saver │           │
│  ├─────────────┤     ├─────────────┤     ├─────────────┤           │
│  │  功耗 ≈ 0W  │     │  功耗 < 5W  │     │  功耗 20-40W│           │
│  │  纯黑画面   │     │ 极简窗景+信息 │     │ 完整沉浸体验 │           │

```

### 1.3 与iPhone全天候显示的对照

| 层级 | iPhone全天候显示 | A500窗景 |
|------|----------------|---------|
| **Level 0** | 锁定 → 屏幕完全关闭 | **黑屏模式** → 检测无人，屏幕关闭 |
| **Level 1** | AOD显示（时间/通知/壁纸淡化） | **息屏显示** → 超低功耗窗景+信息组件 |
| **Level 2** | 无对应 | **屏保模式** → 完整沉浸式窗景体验 |

## 2. 三层状态定义

### 2.1 状态总览

| 状态 | 名称 | 功耗 | 显示内容 | 触发条件 | 帧率 |
|------|------|------|---------|---------|------|
| **Level 0** | 黑屏（Dark） | ≈ 0W | 无 | 检测无人超过T1 | 0fps |
| **Level 1** | 息屏显示（AOD） | < 5W | 极简窗景 + 信息挂件 | 无人时间T2 / 检测有人 | 1-5fps |
| **Level 2** | 屏保（Screensaver） | 20-40W | 完整窗景场景 | 用户主动进入 / 定时触发 | 30-60fps |

### 2.2 状态定义详解

#### Level 0：黑屏（Dark Screen）

**定义**：电视进入完全关闭状态，屏幕不显示任何内容，仅保留基础电源和传感器监听。

**核心特征**：
- 功耗 ≈ 0W（仅传感器待机功耗 < 0.5W）
- 屏幕完全熄灭，不发光
- 人体传感器持续工作
- 可通过语音/遥控器唤醒

**适用场景**：
- 用户明确表示要睡觉/离开
- 长时间（>2小时）无人在场
- 用户主动切换到"关机"模式

#### Level 1：息屏显示（AOD）

**定义**：在用户在场但不观看时，以极低功耗维持一幅「微光窗景」，显示时间和天气等基础信息。

**核心特征**：
- 功耗 < 5W（整机）
- 极简窗景画面（三种滤镜风格可选）
- 底部固定信息挂件（时间/天气/温度/状态）
- 超低帧率（1-5fps）
- 亮度 3%-12%

**适用场景**：
- 用户在客厅但未主动看电视（如躺着休息、看书）
- 夜间作为背景氛围
- 作为黑屏与屏保之间的过渡态

#### Level 2：屏保（Screen Saver）

**定义**：完整的沉浸式窗景体验，展现全部动态效果、叙事角色和每日一诗。

**核心特征**：
- 功耗 20-40W（完整渲染）
- 五大场景通道完整展示
- 每日一诗仪式感
- 窗剧场叙事角色
- 30-60fps流畅动画
- 支持用户主动进入/退出

**适用场景**：
- 用户主动进入窗景应用
- 定时启动（如每晚8点自动开启）
- 作为客厅装饰/背景氛围

## 4. 黑屏模式（Dark Screen）

### 4.1 设计定义

**Level 0：黑屏模式** 是三层架构中最节能的状态，适用于用户明确不在场或需要完全关闭显示的场景。

### 4.2 核心特性

| 特性 | 说明 |
|------|------|
| **功耗** | ≈ 0W（仅传感器待机 < 0.5W） |
| **屏幕状态** | 完全熄灭，无任何发光 |
| **传感器** | 人体传感器持续工作（毫米波/红外） |
| **唤醒方式** | 人体检测 / 遥控器按键 / 语音唤醒 |
| **响应延迟** | 人体检测唤醒 < 500ms |

### 4.3 触发条件

```
自动进入黑屏的条件（同时满足）：
├── 条件1：检测无人在场（人体传感器持续N分钟无检测）
├── 条件2：当前不是用户主动观看状态
└── 条件3：不是每日定时窗景时段

自动退出黑屏的条件（满足任一）：
├── 条件1：人体传感器检测到有人进入
├── 条件2：用户按遥控器任意按键
├── 条件3：用户语音唤醒（如"小维，打开窗景"）
└── 条件4：定时任务触发（如每日窗景提醒）
```

### 4.4 唤醒过渡效果

```
黑屏 → 息屏显示（检测有人唤醒）

时间轴: 0.0s ──── 0.5s ──── 1.0s ──── 1.5s
        │
        ├── 0.0s: 屏幕完全熄灭
        │
        ├── 0.0-0.3s: 传感器确认有人（防误触发）
        │
        ├── 0.3-1.0s: 屏幕开始发光，亮度 0% → 5%
        │              曲线: ease-out
        │
        ├── 1.0-1.3s: AOD画面淡入
        │
        └── 1.5s: 息屏显示完全呈现
```

### 4.5 与传统待机的区别

| 对比项 | 传统待机 | 黑屏模式（Dark） |
|--------|---------|----------------|
| **功耗** | 1-3W | < 0.5W |
| **屏幕** | 黑画面（LCD背光关闭） | 完全熄灭（OLED像素关闭） |
| **传感器** | 不工作 | 持续工作 |
| **唤醒方式** | 仅遥控器 | 传感器 + 遥控器 + 语音 |
| **响应速度** | 即时 | < 500ms（传感器唤醒） |

## 5. 息屏显示模式（AOD）

### 5.1 设计定义

**Level 1：息屏显示模式** 参照iPhone全天候显示的设计理念，在用户在场但不主动观看时，以极低功耗维持一幅「微光窗景」，显示时间和天气等基础信息。

### 5.2 核心特性

| 特性 | 说明 |
|------|------|
| **功耗** | < 5W（整机） |
| **帧率** | 1-5fps（超低帧率） |
| **亮度** | 3%-12%（极低亮度） |
| **显示内容** | 极简窗景画面 + 信息挂件 |
| **刷新策略** | 每分钟更新时间，每30分钟更新天气 |

### 5.3 视觉设计

#### 5.3.1 三种滤镜风格（与现有设计一致）

| 风格 | 功耗 | 特点 | 最佳场景 |
|------|------|------|---------|
| **微光写实** | ~4W | 保留写实感，仅降低亮度 | 全场景 |
| **水墨剪影** | ~3W | 东方美学，纯灰度剪影 | 梦江南/大都会 |
| **星座光点** | ~2W | 极致极简，稀疏光点 | 新城际/寂静海 |

#### 5.3.2 信息挂件设计（与现有设计一致）

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│              极 简 窗 景 画 面                        │
│           （三种滤镜风格可选）                        │
│                                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│  23:42    ☁ 阴    🌡 22°C     ·· 助眠中             │
│  时间      天气       温度        状态               │
└─────────────────────────────────────────────────────┘
```

### 5.4 AOD与iPhone全天候显示的对照

| 维度 | iPhone全天候显示 | A500窗景AOD |
|------|----------------|------------|
| **显示内容** | 时间/日期/通知/壁纸淡化 | 时间/天气/温度/极简窗景 |
| **视觉风格** | 保留锁屏壁纸（淡化） | 专属AOD滤镜（微光/水墨/光点） |
| **信息密度** | 高（通知图标/日程等） | 低（仅基础信息） |
| **刷新策略** | 1Hz超低刷新 | 1-5fps |
| **智能感知** | Face ID检测视线 | 人体传感器检测在场 |
| **唤醒方式** | 抬腕/点击 | 人体检测/遥控器/语音 |

### 5.5 进入/退出动画

#### 进入AOD（从屏保/用户离开）

```
时间轴: 0.0s ──── 1.0s ──── 2.0s ──── 3.0s

阶段1（0-1s）: 窗景画面从全亮渐暗至AOD亮度
  亮度: 100% → 20%
  曲线: ease-out

阶段2（1-2s）: 应用AOD滤镜
  滤镜: 标准画面 → 微光写实/水墨剪影/星座光点
  曲线: ease-in-out

阶段3（2-3s）: 信息挂件淡入
  透明度: 0 → 0.7
  从底部向上微滑 12px + 微弹跳
```

#### 退出AOD（用户唤醒）

```
时间轴: 0.0s ──── 0.5s ──── 1.0s ──── 1.5s ──── 2.0s

阶段1（0-0.5s）: 信息挂件淡出
  透明度: 0.7 → 0

阶段2（0.5-1.5s）: 中心光晕扩散唤醒效果
  从屏幕中心扩展，模拟"睁开眼睛"
  亮度: 3% → 15% → 30%

阶段3（1.5-2.0s）: 完整窗景呈现
  滤镜撤销 → 完整色彩/亮度恢复
```

## 6. 屏保模式（Screen Saver）

### 6.1 设计定义

**Level 2：屏保模式** 是A500窗景的完整沉浸式体验模式，展现全部动态效果、叙事角色和每日一诗，让电视成为客厅的一道美丽风景。

### 6.2 核心特性

| 特性 | 说明 |
|------|------|
| **功耗** | 20-40W（完整渲染） |
| **帧率** | 30-60fps（流畅动画） |
| **亮度** | 20%-100%（可调节） |
| **场景** | 五大场景通道完整展示 |
| **功能** | 每日一诗/窗剧场/智能联动 |

### 6.3 完整功能模块

#### 6.3.1 每日一诗

```
唤醒时展示（5秒）：
"月落乌啼霜满天，江枫渔火对愁眠"
         —— 张继《枫桥夜泊》

匹配逻辑：f(时段, 天气, 季节)
```

#### 6.3.2 窗剧场叙事角色

| 场景 | 角色 | 行为 |
|------|------|------|
| 新城际 | 无人机 | 城市上空飞行轨迹 |
| 大都会 | 小猫 | 街角踱步、躺卧 |
| 梦江南 | 摇橹船 | 水面缓慢划过 |
| 曼陀罗 | 松鼠 | 树枝间跳跃 |
| 寂静海 | 海鸥 | 海岸线盘旋 |

#### 6.3.3 智能时间/天气联动

| 时段 | 天空色彩 | 光源 |
|------|---------|------|
| 晨间 06:00-10:00 | 橙黄渐变 → 天蓝 | 朝阳 |
| 日间 10:00-16:00 | 天蓝 → 淡蓝 | 太阳 |
| 暮间 16:00-20:00 | 金橙 → 紫红 | 夕阳 |
| 夜间 20:00-06:00 | 深蓝 → 墨黑 | 月光/星光 |

### 6.4 屏保与iPhone对照

| 维度 | iPhone锁屏 | A500屏保模式 |
|------|-----------|-------------|
| **定位** | 主屏幕替代 | 客厅装饰/背景氛围 |
| **内容** | 通知/小组件/壁纸 | 完整窗景/诗词/角色 |
| **交互** | 可操作（滑动/点击） | 半可操作（遥控器切换） |
| **目的** | 快速获取信息 | 美学享受/氛围营造 |

### 7.4 用户体验原则

1. **无感知过渡**：三层状态之间的切换应该让用户感觉自然，不会被打断
2. **主动提醒克制**：屏保循环提醒不要过于频繁，避免打扰
3. **唤醒一致性**：无论从哪种状态唤醒，都应该有一致的体验
4. **能耗可见性**：在设置中向用户展示各模式的预估功耗

## 8. 功耗规格与技术实现

### 8.1 功耗规格汇总

| 状态 | 功耗范围 | 屏幕功耗 | 系统功耗 | 说明 |
|------|---------|---------|---------|------|
| **黑屏** | < 0.5W | ~0W | < 0.5W | 仅传感器待机 |
| **息屏显示** | 3-5W | 2-4W | < 1W | 极低亮度显示 |
| **屏保** | 20-40W | 15-35W | < 5W | 完整渲染 |

### 8.2 与iPhone功耗对比

| 设备 | AOD功耗 | 电池容量 | AOD耗电比 |
|------|---------|---------|----------|
| iPhone 15 Pro | ~2% / 小时 | 4422 mAh | 极低 |
| iPad Pro 12.9" | ~5-8% / 小时 | 40.88 Wh | 中等 |
| A500窗景（TV） | 3-5W | AC供电 | 不敏感 |

### 8.3 技术实现要点

#### 8.3.1 传感器选择

| 传感器类型 | 优点 | 缺点 | 推荐场景 |
|-----------|------|------|---------|
| 毫米波雷达 | 检测精度高，可检测呼吸 | 成本较高 | 高端型号 |
| 红外传感器 | 成本低，响应快 | 受温度影响 | 性价比型号 |
| 摄像头AI | 功能丰富 | 隐私顾虑 | 可选功能 |

#### 8.3.2 功耗优化策略

```
黑屏模式：
├── 完全关闭屏幕供电
├── 仅保留传感器供电
└── 系统进入深度休眠

息屏显示模式：
├── OLED像素级控制（仅点亮内容区域）
├── 降低刷新率至 1-5fps
├── 关闭HDR/高亮度
├── 降低CPU/GPU频率
└── 关闭不必要的后台服务

屏保模式：
├── 标准渲染管线
├── 全帧率运行
├── 可选：根据环境光调节亮度
└── 音频可选（环境音）
```
