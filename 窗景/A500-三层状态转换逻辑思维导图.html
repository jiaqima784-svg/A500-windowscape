三层状态详解

🌑
Level 0 · 黑屏模式
Dark Screen · 最节能状态

屏幕完全关闭，仅保留传感器监听，功耗≈0W。

  • 功耗：< 0.5W（仅传感器待机）
  • 触发：检测无人在场超过 T1
  • 唤醒：人体检测 / 遥控器 / 语音
  • 响应：< 500ms 传感器唤醒
传感器监听 超低功耗 零显示
🌙
Level 1 · 息屏显示
Always-On Display · 氛围陪伴

极低功耗显示「微光窗景」，配合信息挂件，参照iPhone AOD设计。

  • 功耗：< 5W（整机）
  • 帧率：1-5fps 超低刷新
  • 亮度：3%-12% 极低亮度
  • 内容：极简窗景 + 时间/天气/温度
3种滤镜风格 信息挂件 极光/水墨/光点
🖼️
Level 2 · 屏保模式
Screen Saver · 完整沉浸体验

完整的沉浸式窗景体验，展现全部动态效果与叙事角色。

  • 功耗：20-40W（完整渲染）
  • 帧率：30-60fps 流畅动画
  • 亮度：20%-100% 可调节
  • 功能：每日一诗 / 窗剧场 / 智能联动
5大场景通道 叙事角色 每日一诗

典型使用场景

☀️
场景1：用户主动开启
回家后想放松一下
遥控器按下「电源」
→ 黑屏 → 屏保（2s渐亮）
→ 每日一诗展示（5s）
→ 完整窗景呈现
📖
场景2：在场但不观看
客厅休息/看书
屏保 → 5分钟无操作
→ 息屏显示（3s渐暗）
→ 微光窗景 + 信息挂件
→ 作为背景氛围陪伴
🌙
场景3：用户离开
睡觉/外出
息屏显示 → 30分钟无人
→ 黑屏（2s渐暗熄灭）
→ 传感器持续监听
→ 检测有人自动唤醒
