## 一、项目概述

### 1.1 背景与目标

#### 1.1.1 项目背景

A500 窗景是一款面向智能电视的沉浸式视觉体验应用，旨在为用户提供随天气、季节变化的动态窗景画面，让电视在不使用时成为客厅的一道美丽风景。

**核心问题**：现有的息屏显示（AOD）模式采用一刀切的设计，无法覆盖用户"在场但不观看"的所有场景，导致：
- 用户主动关闭AOD时，电视处于纯黑画面，缺乏美感
- AOD常亮时功耗较高，用户体验与能耗难以平衡
- 缺乏针对不同使用场景的精细化设计

#### 1.1.2 设计参照

参照 **iPhone 全天候显示（Always-On Display）** 的设计理念，重新定义 A500 窗景的息屏状态层次：

> iPhone 全天候显示通过分层设计，在锁屏（关闭）和正常显示之间，创造了 AOD（低功耗信息展示）这一中间状态，实现了用户体验与功耗的平衡。

#### 1.1.3 项目目标

| 目标 | 描述 | 衡量指标 |
|------|------|---------|
| **体验目标** | 实现"有人在场"的精细化状态分层，覆盖完整使用场景 | 用户场景覆盖率 ≥ 95% |
| **功耗目标** | 根据场景智能调节功耗，实现最优能耗比 | AOD功耗 < 5W，黑屏功耗 ≈ 0W |
| **唤醒目标** | 提供流畅、一致的唤醒体验，响应时间 < 2s | 唤醒满意度 ≥ 90% |
| **转化目标** | 通过智能提醒，提升屏保模式使用时长 | 屏保使用时长提升 30% |

### 1.2 产品定位

| 维度 | 描述 |

## 三、功能需求

### 3.1 Level 0：黑屏模式

#### 3.1.1 功能描述

黑屏模式是三层架构中最节能的状态，适用于用户明确不在场或需要完全关闭显示的场景。

**核心特性**：
- 屏幕完全熄灭，不发光（OLED像素完全关闭）
- 仅保留人体传感器持续工作（毫米波雷达 / 红外传感器）
- 可通过多种方式唤醒：人体检测 / 遥控器按键 / 语音唤醒
- 人体检测唤醒响应时间 < 500ms

#### 3.1.2 进入条件（同时满足）

```
├── 条件1：检测无人在场
│   └── 人体传感器持续 T1 时间无检测（默认30分钟）
├── 条件2：当前不是用户主动观看状态
│   └── 用户未在操作遥控器或触摸屏幕
└── 条件3：不在每日定时窗景时段
    └── 用户未设置定时启动窗景
```

#### 3.1.3 退出条件（满足任一）

```
├── 条件1：人体传感器检测到有人进入
│   └── 响应延迟 < 500ms
├── 条件2：用户按遥控器任意按键
├── 条件3：用户语音唤醒（如"小维，打开窗景"）
└── 条件4：定时任务触发（如每日窗景提醒）
```

#### 3.1.4 技术规格

| 项目 | 规格 | 说明 |
|------|------|------|
| 整机功耗 | < 0.5W | 仅传感器待机功耗 |
| 屏幕状态 | 完全熄灭 | OLED像素关闭 |
| 传感器功耗 | < 0.1W | 毫米波雷达待机 |
| 唤醒延迟 | < 500ms | 人体检测到屏幕发光 |
| 防误触发 | 300ms 二次确认 | 避免短暂路过误触发 |

### 3.2 Level 1：息屏显示（AOD）

#### 3.2.1 功能描述

参照 iPhone 全天候显示的设计理念，在用户在场但不主动观看时，以极低功耗维持一幅「微光窗景」，显示时间和天气等基础信息。

**核心特性**：
- 功耗 < 5W（整机），极低能耗
- 三种滤镜风格可选：微光写实 / 水墨剪影 / 星座光点
- 超低帧率（1-5fps），每秒刷新1-5次
- 极低亮度（3%-12%），不刺眼
- 底部固定信息挂件：时间 / 天气 / 温度 / 状态

#### 3.2.2 三种滤镜风格

| 风格 | 功耗 | 视觉效果 | 适用场景 | 最佳匹配 |
|------|------|---------|---------|---------|
| **微光写实** | ~4W | 保留写实感，仅降低亮度 | 全场景通用 | 新城际 / 曼陀罗 |
| **水墨剪影** | ~3W | 东方美学，纯灰度剪影 | 文化氛围 | 梦江南 / 大都会 |
| **星座光点** | ~2W | 极致极简，稀疏光点 | 夜间/助眠 | 寂静海 / 新城际 |

#### 3.2.3 信息挂件设计

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                   极 简 窗 景 画 面                          │
│                （三种滤镜风格可选）                           │
│                                                             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   23:42          ☁ 阴           🌡 22°C          ·· 助眠中   │
│   时间           天气            温度              状态       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 3.2.4 进入/退出动画规格

**进入AOD（从屏保/用户离开）**：

| 阶段 | 时间 | 效果 |
|------|------|------|
| 阶段1 | 0-1s | 窗景画面从全亮渐暗至AOD亮度（100% → 20%） |
| 阶段2 | 1-2s | 应用AOD滤镜（标准画面 → 微光写实/水墨剪影/星座光点） |
| 阶段3 | 2-3s | 信息挂件淡入（透明度 0 → 0.7，向上微滑12px） |

**退出AOD（用户唤醒）**：

| 阶段 | 时间 | 效果 |
|------|------|------|
| 阶段1 | 0-0.5s | 信息挂件淡出（透明度 0.7 → 0） |
| 阶段2 | 0.5-1.5s | 中心光晕扩散唤醒效果（模拟"睁开眼睛"） |
| 阶段3 | 1.5-2.0s | 完整窗景呈现（滤镜撤销，色彩/亮度恢复） |

#### 3.2.5 技术规格

| 项目 | 规格 | 说明 |
|------|------|------|
| 整机功耗 | < 5W | 极低功耗显示 |
| 帧率 | 1-5fps | 每秒刷新1-5次 |
| 亮度 | 3%-12% | 极低亮度，不刺眼 |
| 信息刷新 | 每分钟更新时间 | 每30分钟更新天气 |
| 画质模式 | HDR关闭 | 降低渲染压力 |

### 3.3 Level 2：屏保模式

#### 3.3.1 功能描述

完整的沉浸式窗景体验模式，展现全部动态效果、叙事角色和每日一诗，让电视成为客厅的一道美丽风景。

**核心特性**：
- 功耗 20-40W（完整渲染）
- 五大场景通道完整展示：新城际 / 大都会 / 梦江南 / 曼陀罗 / 寂静海
- 每日一诗仪式感展示
- 窗剧场叙事角色（无人机、小猫、摇橹船等）
- 30-60fps 流畅动画

#### 3.3.2 核心功能模块

**每日一诗**：

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                        「每日一诗」                           │
│                                                             │
│               月落乌啼霜满天，江枫渔火对愁眠                    │
│                        —— 张继《枫桥夜泊》                     │
│                                                             │
│                   匹配：夜间 + 秋季 + 江南                     │

└─────────────────────────────────────────────────────────────┘

触发时机：唤醒时展示（5秒自动渐隐）
匹配逻辑：f(时段, 天气, 季节) → 智能推荐
```

**窗剧场叙事角色**：

| 场景 | 角色 | 行为动画 | 出现频率 |
|------|------|---------|---------|
| 新城际 | 无人机 | 城市上空飞行轨迹 | 偶发（每10分钟） |
| 大都会 | 小猫 | 街角踱步、躺卧 | 偶发 |

**智能时间/天气联动**：

|------|---------|---------|---------|
| 晨间 06:00-10:00 | 橙黄渐变 → 天蓝 | 朝阳升起 | 云彩飘动 |

### 4.2 自动转换规则

| 当前状态 | 触发条件 | 目标状态 | 过渡动画 | 响应时间 |
|---------|---------|---------|---------|---------|
| **屏保** | 用户主动退出 / 无操作 T3 | 息屏显示 | 3.0s 渐暗动画 | < 3s |

### 4.3 时间参数配置

| **T3** | 屏保无操作 → 息屏显示 | 15分钟 | 5min / 15min / 30min | ✓ |

### 4.4 唤醒过渡效果

**黑屏 → 息屏显示（检测有人唤醒）**：

```

        │

        │
        ├── 0.0-0.3s: 传感器确认有人（防误触发）
        │
        ├── 0.3-1.0s: 屏幕开始发光，亮度 0% → 5%
        │              曲线: ease-out
        │
        ├── 1.0-1.3s: AOD画面淡入
        │
        └── 1.5s: 息屏显示完全呈现
```

### 5.2 遥控器交互

| 操作 | 触发结果 |
|------|---------|
| 按「电源」键 | 从当前状态 → 屏保模式（默认行为） |
| 按「返回」键 | 从屏保 → 退出窗景应用 |
| 按「方向键」 | 在屏保模式下切换场景（上/下/左/右） |
| 按「确认」键 | 在屏保模式下显示/隐藏控制面板 |
| 按「菜单」键 | 打开窗景设置页面 |
| 长按「语音」键 | 唤醒语音助手（不退出当前模式） |

### 5.3 语音交互

| 语音指令 | 触发结果 |
|---------|---------|
| "小维，打开窗景" | 黑屏/息屏 → 屏保模式（完整唤醒） |
| "小维，关闭窗景" | 任意状态 → 黑屏模式 |
| "小维，切换到梦江南" | 屏保模式 → 切换场景 |
| "小维，明天天气" | 显示天气信息（不退出当前模式） |
| "小维，进入助眠模式" | 切换到寂静海 + 助眠设置 |
| "小维，关闭屏保" | 屏保 → 息屏显示 |

### 5.4 用户体验原则

1. **无感知过渡**：三层状态之间的切换应该让用户感觉自然，不会被打断
2. **主动提醒克制**：屏保循环提醒不要过于频繁，避免打扰
3. **唤醒一致性**：无论从哪种状态唤醒，都应该有一致的体验
4. **能耗可见性**：在设置中向用户展示各模式的预估功耗
5. **场景智能**：根据时段、天气自动推荐最适合的窗景

## 六、技术实现要求

### 6.1 传感器选型

| 传感器类型 | 优点 | 缺点 | 推荐场景 | 成本 |
|-----------|------|------|---------|------|
| **毫米波雷达** | 检测精度高，可检测呼吸 | 成本较高 | 高端型号 | 高 |
| **红外传感器** | 成本低，响应快 | 受温度影响 | 性价比型号 | 低 |
| **摄像头AI** | 功能丰富 | 隐私顾虑 | 可选功能 | 中 |

**推荐方案**：
- 高端型号：毫米波雷达（检测呼吸级别）
- 性价比型号：红外传感器（成本优先）
- 可选功能：摄像头AI（隐私可关闭）

### 6.2 功耗优化策略

#### 黑屏模式
```
├── 完全关闭屏幕供电
├── 仅保留传感器供电（< 0.1W）
└── 系统进入深度休眠
```

#### 息屏显示模式
```
├── OLED像素级控制（仅点亮内容区域）
├── 降低刷新率至 1-5fps
├── 关闭HDR/高亮度
├── 降低CPU/GPU频率至最低
├── 关闭不必要的后台服务
└── 禁用声音输出
```

#### 屏保模式
```
├── 标准渲染管线
├── 全帧率运行（30-60fps）
├── 可选：根据环境光调节亮度
├── 可选：音频输出（环境音）
└── 可选：HDR增强（高端内容）
```

### 6.3 功耗规格汇总

| 状态 | 功耗范围 | 屏幕功耗 | 系统功耗 | 说明 |
|------|---------|---------|---------|------|
| **黑屏** | < 0.5W | ~0W | < 0.5W | 仅传感器待机 |
| **息屏显示** | 3-5W | 2-4W | < 1W | 极低亮度显示 |
| **屏保** | 20-40W | 15-35W | < 5W | 完整渲染 |

### 6.4 响应时间要求

| 事件 | 响应时间要求 | 说明 |
|------|------------|------|
| 人体检测 → AOD唤醒 | < 500ms | 传感器触发到屏幕开始发光 |
| 遥控器按键 → 屏保唤醒 | < 1s | 按键到完整画面呈现 |
| 语音唤醒 → 屏保唤醒 | < 2s | 语音识别 + 执行 |
| AOD → 屏保（用户进入） | < 2s | 渐亮动画完成 |
| 屏保 → AOD（用户离开） | < 3s | 渐暗动画完成 |
| AOD → 黑屏（无人检测） | < 2s | 渐暗 + 完全熄灭 |
