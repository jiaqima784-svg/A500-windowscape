## 1. 设计概览

### 1.1 定位

息屏显示模式（Always-On Display，AOD）是 A500 窗景产品的**核心低功耗陪伴模式**，在用户不主动交互时，以极低功耗维持一幅「微光窗景」，实现：

- **节能**：整机功耗 < 5W，约为标准模式的 1/20
- **美观**：保留窗景核心美学要素（光影、氛围、时间感）
- **无缝**：从标准模式 → MiniLED 模式 → AOD 模式过渡自然，用户感知为零干扰

### 1.2 触发逻辑

```
用户操作 ──▶ 标准模式（全亮度）
  │
  ├─ 无操作 1~5min（可配置）
  │     ▼
  │   MiniLED 模式（类纱帘效果，中等亮度）
  │
  ├─ 无操作 15~30min（可配置）
  │     ▼
  │   息屏显示模式（AOD，极低亮度）
  │
  └─ 检测到用户靠近 / 遥控器按键 / 触屏
        ▼
      唤醒 → 标准模式（带入场动画）
```

### 1.3 五种场景通道在 AOD 下的表现

| 场景通道 | AOD 视觉主题 | 滤镜风格 | 核心色彩 |
|---------|-------------|---------|---------|
| 新城际/科技新城 | 暗夜天际线 | 冷蓝单色 + 微光点 | #0A1628 → #1B3A5C |
| 大都会/文艺老街 | 暖黄街灯 | 琥珀暖棕单色 | #1A120B → #3D2B1F |
| 梦江南/水调楼阁 | 水墨夜色 | 灰绿双色渐变 | #0D1117 → #1B2D1F |
| 曼陀罗/郊外庄园 | 月光田园 | 冷紫微蓝 | #120D1A → #1E1630 |
| 寂静海/海边小屋 | 深海幽蓝 | 纯蓝单色 | #050A14 → #0A1931 |

## 2. 息屏显示模式视觉效果图

### 2.1 三种滤镜风格定义

AOD 模式下提供 **3 种滤镜风格**，用户可在设置中切换：

#### 风格 A：微光写实（Glimmer Realistic）

- **理念**：最大程度保留窗景的写实感，仅将亮度和对比度降至极低
- **渲染方式**：原始渲染管线 → 亮度曲线压缩 → 对比度映射 → 色彩去饱和（降至 15%）
- **适用场景**：所有场景
- **功耗等级**：中（约 4W）

```
视觉示意（以"寂静海/海边小屋"为例）:

    ╔══════════════════════════════════════════╗
    ║  ┌────────────────────────────────────┐  ║
    ║  │                                    │  ║
    ║  │         ░░░░░░░░░░░░░░            │  ║  ← 极远处的海平线轮廓（5% 亮度）
    ║  │       ░░              ░░░          │  ║
    ║  │     ░░    月光反射      ░░░        │  ║  ← 微弱月光在水面的反射带（8% 亮度）
    ║  │    ░                    ░░         │  ║
    ║  │   ░      海面微光         ░        │  ║  ← 海面波纹微光（3-6% 亮度脉冲）
    ║  │                                    │  ║
    ║  │                                    │  ║
    ║  │  ───── 窗台轮廓 ─────              │  ║  ← 窗台剪影（12% 亮度）
    ║  └────────────────────────────────────┘  ║
    ║                                          ║
    ║  [时间]  [天气]                   [温度]  ║  ← 信息挂件（详见 §3）
    ╚══════════════════════════════════════════╝

    整体色调: #050A14（背景）→ #0A1931（高光区域）
    全局亮度: 3% ~ 12%
    饱和度:   15%（原始饱和度的 15%）
```

#### 风格 B：水墨剪影（Ink Silhouette）

- **理念**：将窗景抽象为水墨画风格的剪影层，只保留轮廓和层次关系
- **渲染方式**：边缘检测 → 轮廓提取 → 2~3 层灰度叠加 → 水墨晕染后处理
- **适用场景**：梦江南/水调楼阁、大都会/文艺老街（最匹配东方/复古美学）
- **功耗等级**：低（约 3W）

```
视觉示意（以"梦江南/水调楼阁"为例）:

    ╔══════════════════════════════════════════╗
    ║  ┌────────────────────────────────────┐  ║
    ║  │                                    │  ║
    ║  │        ▓▓▓▓▓▓▓                     │  ║  ← 远山剪影层（10% 亮度，2px 模糊）
    ║  │      ▓▓      ▓▓▓                   │  ║
    ║  │    ▓▓   楼阁轮廓    ▓▓             │  ║  ← 中景建筑剪影（15% 亮度）
    ║  │   ▓                  ▓             │  ║
    ║  │  ▓    ~~~ 水面 ~~~    ▓            │  ║  ← 水面用 2px 虚线暗示（6% 亮度）
    ║  │                                    │  ║
    ║  │                                    │  ║
    ║  │  ═════ 窗台 ═════                  │  ║  ← 窗台线条（18% 亮度）
    ║  └────────────────────────────────────┘  ║
    ║                                          ║
    ║  [时间]  [天气]                   [温度]  ║
    ╚══════════════════════════════════════════╝

    整体色调: #0D1117（墨黑）→ #1B2D1F（墨绿）→ #2A1F2D（墨紫）
    亮度层级: 3 级（远 5% / 中 12% / 近 18%）
    风格特征: 边缘柔和（2-3px 高斯模糊），无色彩，纯灰度
```

#### 风格 C：星座光点（Starlight Dots）

- **理念**：将窗景中最核心的视觉信息提炼为稀疏的光点阵列，极致极简
- **渲染方式**：场景特征点提取 → 稀疏光点映射 → 呼吸闪烁
- **适用场景**：新城际/科技新城（科技感最强）、寂静海/海边小屋（星空感）
- **功耗等级**：极低（约 2W）

```
视觉示意（以"新城际/科技新城"为例）:

    ╔══════════════════════════════════════════╗
    ║  ┌────────────────────────────────────┐  ║
    ║  │                                    │  ║
    ║  │     ·          ·    ·              │  ║  ← 城市光点（随机分布，2-8% 亮度呼吸）
    ║  │          ·  ·         ·  ·         │  ║
    ║  │   ·        ───天际线───      ·      │  ║  ← 天际线用 1px 微线暗示（4% 亮度）
    ║  │        ·              ·            │  ║
    ║  │    ·          ·          ·         │  ║  ← 近景光点（较大，8-12% 亮度）
    ║  │                                    │  ║
    ║  │                                    │  ║
    ║  │  ───── 窗台 ─────                  │  ║  ← 窗台线条（10% 亮度）
    ║  └────────────────────────────────────┘  ║
    ║                                          ║
    ║  [时间]  [天气]                   [温度]  ║
    ╚══════════════════════════════════════════╝

    整体色调: #0A1628（深空蓝背景）
    光点颜色: #3B82F6（冷蓝）/ #60A5FA（亮蓝）/ #93C5FD（微蓝）
    光点数量: 15-40 个（根据场景复杂度）
    光点大小: 1-3px，近大远小
    呼吸频率: 2-4 秒/周期，各光点相位随机偏移
```

### 2.2 三种滤镜风格参数对比表

| 参数 | 微光写实 A | 水墨剪影 B | 星座光点 C |
|------|-----------|-----------|-----------|
| 全局亮度 | 3%-12% | 5%-18%（3级） | 2%-12%（光点） |
| 背景色 | 场景映射 | #0D1117 | #0A1628 |
| 饱和度 | 15% | 0%（纯灰度） | 80%（冷蓝系） |
| 对比度 | 原始 × 0.3 | N/A（剪影） | N/A（光点） |
| 渲染负载 | 中 | 低 | 极低 |
| 预估功耗 | ~4W | ~3W | ~2W |
| 最佳场景 | 全场景 | 梦江南/大都会 | 新城际/寂静海 |
| 信息密度 | 高 | 中 | 低 |

## 3. 信息挂件设计规范

### 3.1 挂件组成

AOD 模式下，屏幕底部固定显示一个**极简信息挂件**，包含：

```
    ┌─────────────────────────────────────────┐
    │  23:42    ☁ 阴    🌡 22°C     ·· 睡眠中  │
    │  ↑        ↑         ↑            ↑      │
    │  时间     天气       温度          状态    │
    └─────────────────────────────────────────┘
```

| 元素 | 内容 | 刷新频率 | 可见性 |
|------|------|---------|--------|
| 时间 | HH:MM，24 小时制 | 每分钟 | 常显 |
| 天气 | 图标 + 简述（晴/阴/雨/雪） | 每 30 分钟 | 常显 |
| 温度 | 当前室外温度 ±1°C | 每 30 分钟 | 常显 |
| 状态 | 小圆点 + "睡眠中"文字 | 按需 | 仅在睡眠模式时显示 |

### 3.3 挂件自适应亮度算法

```
挂件文字亮度 = clamp(0.4, 0.8, 场景平均亮度 × 3.0 + 0.3)

说明：
- 场景平均亮度：当前 AOD 场景画面的全局平均亮度值（0-1 范围）
- 当场景极暗时，挂件自动提亮到 0.7 以确保可读性
- 当场景较亮时，挂件适度降亮到 0.5 以避免过曝
- 最低不低于 0.4，最高不高于 0.8
```

```
    │                                                 │

    挂件位置: 底部居中

    挂件圆角: 16px
    间距:

      - 图标与文字间距: 12px
```

## 4. 进入/退出动画规范

### 4.1 状态转换总览

```
标准模式 ──────────▶ MiniLED 模式 ──────────▶ AOD 模式
  │                      │                      │
  │  退场 A               │  退场 B               │  退场 C（用户离开）
  │  2.0s                │  3.0s                │  2.5s
  │                      │                      │
  │  入场 A'              │  入场 B'              │  入场 C'（用户返回）
  │  1.5s                │  2.5s                │  2.0s
  │                      │                      │
  ▼                      ▼                      ▼
```

### 4.2 标准模式 → MiniLED 模式（退场 A）

**动画效果**：类纱帘落下，亮度渐降，细节渐隐

```
关键帧：

  时间轴: 0.0s ──── 0.5s ──── 1.0s ──── 1.5s ──── 2.0s

  亮度:   100% ───── 85% ───── 60% ───── 35% ───── 20%
          ●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●
          ease-out           linear           ease-in

  饱和度: 100% ───── 90% ───── 70% ───── 45% ───── 25%
          ●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●

  模糊:   0px ────── 0px ───── 1px ──── 2px ───── 3px
          ○━━━━━━━━━○━━━━━━━━━●━━━━━━━━━●━━━━━━━━━●

  纱帘遮罩:
    0.0s: 无
    0.5s: 从顶部开始，5% 不透明度的微光层（模拟纱帘上缘）
    1.0s: 纱帘覆盖 50% 画面，不透明度 15%
    1.5s: 纱帘覆盖 90% 画面，不透明度 25%
    2.0s: 纱帘完全覆盖，不透明度 30%（MiniLED 模式到达）

  动画曲线:
    亮度/饱和度: cubic-bezier(0.25, 0.1, 0.25, 1.0)  ← ease-out
    纱帘位置:   cubic-bezier(0.4, 0.0, 0.6, 1.0)    ← 匀速略带缓动
```

### 4.3 MiniLED 模式 → AOD 模式（退场 B）

**动画效果**：纱帘渐隐，滤镜切换，信息挂件淡入

```
关键帧：

  时间轴: 0.0s ──── 0.8s ──── 1.6s ──── 2.4s ──── 3.0s

  亮度:   20% ───── 14% ───── 8% ────── 5% ────── 3%
          ●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●
          ease-out              ease-in-out       ease-in

  饱和度: 25% ───── 18% ────── 12% ───── 8% ────── 5%
          ●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●

  纱帘:   30% ───── 25% ────── 15% ───── 5% ────── 0%
          ○━━━━━━━━━●━━━━━━━━━●━━━━━━━━━○━━━━━━━━━○  ← 纱帘完全消散

  滤镜切换:
    0.0s-1.0s: MiniLED 画面
    1.0s-2.0s: 交叉淡入淡出（MiniLED 画面淡出，AOD 滤镜画面淡入）
    2.0s-3.0s: AOD 滤镜画面完全显现

  信息挂件:
    0.0s-2.0s: 不可见（opacity: 0）
    2.0s-2.8s: 从底部向上滑入 12px + 透明度 0→0.7
    2.8s-3.0s: 稳定在最终位置

  动画曲线:
    亮度/饱和度: cubic-bezier(0.42, 0.0, 0.58, 1.0)  ← ease-in-out
    交叉淡入:   cubic-bezier(0.25, 0.1, 0.25, 1.0)   ← ease-out
    挂件滑入:   cubic-bezier(0.34, 1.56, 0.64, 1.0)  ← 微弹跳（overshoot）
```

### 4.4 AOD 模式 → 标准模式（入场 C'，用户返回唤醒）

**动画效果**：窗景"苏醒"，从黑暗中渐亮

```
关键帧：

  时间轴: 0.0s ──── 0.4s ──── 0.8s ──── 1.2s ──── 1.6s ──── 2.0s

  亮度:   3% ────── 5% ────── 15% ───── 40% ───── 75% ───── 100%
          ○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●
          ease-in              ease-in-out          ease-out

  饱和度: 5% ────── 8% ────── 20% ───── 55% ───── 85% ───── 100%
          ○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●━━━━━━━━━○━━━━━━━━━●

  模糊:   3px ───── 3px ───── 2px ───── 1px ───── 0px ───── 0px
          ●━━━━━━━━━●━━━━━━━━━○━━━━━━━━━○━━━━━━━━━○━━━━━━━━━○

  信息挂件:
    0.0s-0.6s: 保持可见，透明度 0.7→0.3
    0.6s-1.0s: 向下淡出并消失（opacity: 0）

  窗景唤醒特效:
    0.0s-0.8s: 中心光晕效果 —— 屏幕中心一个 20% 半径的圆形光晕

```

### 6.3 渲染管线架构建议

```
标准渲染管线:
  [场景资源] → [动画合成] → [时间/天气叠加] → [色彩管理] → [显示输出]

AOD 渲染管线:
  [场景资源] → [动画合成] → [时间/天气叠加]
    → [AOD 滤镜选择] ──┬─▶ [微光写实滤镜] ─┐
                        ├─▶ [水墨剪影滤镜]  ├→ [亮度/饱和度映射]
                        └─▶ [星座光点滤镜] ─┘
    → [信息挂件叠加] → [MiniLED 背光映射] → [低帧率输出] → [显示输出]

关键差异:
  1. AOD 滤镜选择: 3 选 1，可运行时切换
  2. 亮度/饱和度映射: 将输出压缩到 3%-12% 亮度范围
  3. MiniLED 背光映射: 分区背光优化，关闭无内容区域
  4. 低帧率输出: 1-5fps，使用帧缓存重复输出
```

### 6.4 接口定义（关键）

#### 6.4.1 AOD 模式控制接口

```kotlin
interface AodController {
    // 进入 AOD 模式
    fun enterAodMode(
        sceneId: String,          // 当前场景 ID
        filterStyle: FilterStyle, // A/B/C 滤镜
        transitionDuration: Long  // 过渡时长 (ms)
    ): Boolean

    // 退出 AOD 模式
    fun exitAodMode(
        transitionDuration: Long  // 过渡时长 (ms)
    ): Boolean

    // 切换滤镜风格（在 AOD 模式下）
    fun switchFilterStyle(style: FilterStyle): Boolean

    // 查询当前 AOD 状态
    fun getAodState(): AodState
}

enum class FilterStyle {
    GLIMMER_REALISTIC,   // 微光写实 A
    INK_SILHOUETTE,      // 水墨剪影 B
    STARLIGHT_DOTS       // 星座光点 C
}

data class AodState(
    val isActive: Boolean,
    val currentFilter: FilterStyle,
    val currentScene: String,
    val brightness: Float,     // 0.0-1.0
    val fps: Int,              // 1-5
    val powerConsumption: Float // 瓦特
)
```
